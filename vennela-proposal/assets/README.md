# 💖 Vennela & Akash Love Proposal Website

This interactive love proposal experience is designed for **Vennela**, created with all his heart by **Akash**.

---

### ⚙️ How to Customize:

All names, personal letter content, signature, and runaway NO button reactions can be customized directly from the `config.js` file:

```js
const CONFIG = {
    HER_NAME: "Vennela",
    YOUR_NAME: "Akash",
    PERSONAL_MESSAGE: `...`,
    SIGNATURE: "With all my love,\nAkash ❤️",
    NO_REACTIONS: [...]
};
```

---

### 🖥️ How to Run:

Simply open `index.html` in any web browser!
